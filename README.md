# South Delhi Ortho Surgeons Association — Keynote (May 2026)

7-slide AI keynote by **Dr. Piyush Malik** · Clinical AI Strategist & Architect.

Built with React + Vite + Framer Motion. Deployed via GitHub Actions to GitHub Pages.

## Stack

- React 19 + TypeScript
- Vite 8
- Framer Motion (slide transitions, staggered card entries)
- CSS custom-properties design system (no Tailwind)
- 1920×1080 fixed canvas, scaled via CSS transform to fit viewport

## Local dev

```bash
cd deck
npm install
npm run dev      # local server on :5173
npm run build    # production build → deck/dist
npm run preview  # serve the production build on :4173
```

## Navigation

- Arrow keys / Space — next/prev slide
- Click the dot nav at the bottom right to jump
